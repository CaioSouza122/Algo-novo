# Sistema de Chamados - Suporte Técnico

Projeto web desenvolvido com Python e Flask para simular um sistema de abertura de chamados de suporte técnico, afim de testar meus conhecimentos a respeito das linguagens usadas.

## Tecnologias Utilizadas

- Python
- Flask
- HTML5
- CSS3
- JavaScript

# Como rodar
Depois de clonar o repositório será necessario criar um ambiente virtual 

python -m venv venv

Instale o flask 
pip flask

Agora só rodar com o python app.py
